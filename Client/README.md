# CampusVerse Client

This folder contains the frontend of CampusVerse.

Frontend development is the part of web development that I enjoy the most. I like turning simple ideas into clean interfaces, experimenting with layouts, choosing colors, and adding small animations that make a website feel more polished and interactive.

## My Frontend Journey

While developing this project, I learned that frontend development is not only about making a page look good. A good interface should also be easy to understand, responsive, accessible, and properly connected with the backend.

I worked on this frontend gradually. I first created the basic pages and components, and then improved the design, responsiveness, animations, loading states, error messages, and overall user experience.

Some parts required several attempts before they worked the way I wanted. Fixing those issues helped me understand React and frontend development much better.

## What I Practised

During the development of this frontend, I practised:

* Creating reusable React components
* Managing component state and user interactions
* Building forms with validation and error messages
* Creating responsive layouts for different screen sizes
* Using CSS Modules to keep styles organized
* Adding smooth animations and page transitions
* Working with protected pages and navigation
* Connecting the frontend with backend APIs
* Handling loading, success, empty, and error states
* Creating light and dark themes
* Improving the interface through testing and feedback
* Deploying a Vite application on Vercel

## Design and Animations

Designing the interface was one of my favourite parts of this project.

I experimented with different layouts, themes, cards, buttons, spacing, typography, and animations before selecting the current design. I tried to keep the interface modern while still making it simple enough for a new user to understand.

Animations were added carefully to improve the experience without making the application distracting. I used them for page reveals, transitions, hover feedback, and other small interactions.

## Challenges I Faced

A few frontend challenges I worked through were:

* Keeping the design consistent across different pages
* Making large interactive sections fit properly on different screens
* Preventing unwanted scrolling inside nested sections
* Keeping the UI synchronized with live updates
* Displaying useful messages when the server is unavailable
* Managing environment variables during deployment
* Fixing API and CORS-related issues after deployment
* Maintaining readable code as the project became larger

Solving these problems taught me how to debug using the browser console, Network tab, application logs, and small step-by-step tests.

## Run the Client Locally

Install the dependencies:

```bash
npm install
```

Create a `.env` file inside the `Client` folder:

```env
VITE_API_URL=http://localhost:6001/api
VITE_SOCKET_URL=http://localhost:6001
```

Start the development server:

```bash
npm run dev
```

The terminal will display the local URL where the client is running.
